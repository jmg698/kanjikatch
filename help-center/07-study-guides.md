# Creating study guides

A study guide turns one or more captures into a full lesson handout you can read or print. It's especially useful for class notes: capture the week's slides, then build a single guide to study from.

Each guide includes:

- **Vocabulary** tables
- **Grammar patterns** with examples
- A **kanji** breakdown grouped by JLPT level
- **Practice** exercises (fill-in-the-blank, translation, and personal questions), with an answer key

## Create a guide right after a capture

1. Capture a page and save it to your library.
2. On the summary screen, select **Create study guide**.
3. Wait while KanjiKatch builds your guide. It opens automatically when it's ready.

## Create a guide from one or more captures

1. Select **Guides** in the navigation bar.
2. Select **New guide** (or **Create from captures** if this is your first guide).
3. Under **Choose captures**, check the captures you want to include. You can combine up to 10.
4. Select **Generate guide**.
5. Wait while KanjiKatch writes your guide. This usually takes under a minute.

> **Note:** A guide is built only from the items you *saved* from each capture. If you unchecked something on the review screen, it won't be in the guide.

## Print a guide

1. Select **Guides**, then open the guide.
2. Select **Print**.
3. In your browser's print dialog, print the guide or save it as a PDF.

## Delete a guide

1. Select **Guides**, then open the guide.
2. Select the trash icon.
3. Confirm that you want to delete it.

Deleting a guide doesn't remove anything from your library.

## Troubleshooting

**"Nothing was saved from these captures yet"**
The captures you picked don't have any saved items. Capture a page, save some items, and try again.

**"Our AI is temporarily overloaded"**
Wait a minute and try again.
